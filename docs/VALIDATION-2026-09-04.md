# 主题 1.1 与博客复验

日期：2026-09-04。主题发布为 [v1.1.0](https://github.com/CHEology/hexo-theme-bluenote/tree/v1.1.0)，提交 `2c7029d`；博客升级提交 `9ad4d7b`。[Pages 构建和部署成功](https://github.com/CHEology/bluenote/actions/runs/33928758603)。未新增主题 CI，博客原有 Pages 工作流保持不变。

## 结论

本轮未发现会阻碍阅读的页面、移动布局或加载问题。修复了配置开关失效、搜索状态和焦点、普通文章被图片数量误判成摄影版式，以及手机首页延迟显示标语的问题。主题已经具备独立安装、独立示例和可选 Gallery；不需要复制本站的文章、照片或私密档案。

## 交付内容

- 普通文章保持正文列、已有目录与图注。摄影版式由 `photo_layout: true` 显式选择；本站《秋之纽约_2023.11》只增加此 Front Matter，正文逐字比对无变化。
- `search.enable`、`post.lightbox`、搜索索引路径、文章语言和显式默认配色生效；私密文章清单改为站点显式配置，通用主题不再默认请求它。
- 搜索有加载、无结果、失败和重试状态；打开时背景不可操作，Tab 在弹窗内循环，关闭后恢复入口焦点。兼容 WebKit 不自动聚焦鼠标点击链接的行为。
- Gallery 的渲染、验证、随机抽选、成组照片和大图观看迁入主题。默认关闭，路径、语言、按钮文案可配置，仅 Gallery 页面加载模块资源；照片清单和照片仍属于博客。
- 主题仓库提供最小示例站、六张桌面／手机／深色截图和安装说明。示例使用原创几何图案与示例文字；其 `.npmrc` 安装打包副本，避免目录链接递归。
- 手机直接显示完整标语，桌面保留打字效果。站点小图标由 429,719 bytes 的原图改用 5,776 bytes 的 64px 副本；另提供 180px touch icon 和 256px About 头像，保留原图。

## 验证范围

1. 临时移走本地主题开发目录后，以锁定的 `v1.1.0` 执行 `npm ci` 和 `npm run check`：5 篇文章、23 个 HTML 页面、私密档案格式检查和 24 项 Gallery 检查通过。安装副本与开发目录的 62 个运行时资源逐字节一致。
2. 全站浏览器检查：23 页 × 320/390/768/1024/1440px × 明暗模式 × Chromium/WebKit，共 460 组。未发现横向溢出、首屏可见坏图、脚本错误、失败资源或第三方请求。
3. 64 个视觉状态与修改前基线对比通过。允许差异限定为手机静态标语及 Gallery 操作文字的对比度；未放宽其他页面的截图阈值。正文文本检查通过。
4. 主题自己的四项构建集成检查及 Chromium/WebKit 交互检查通过，涵盖域名根目录、子目录、配置关闭、普通多图文章、键盘看图、搜索无结果／重试／焦点、Gallery 抽选和五种屏宽；另验证显式浅色默认值不被系统深色覆盖。
5. 完整示例在全新临时目录安装并构建成功；Hexo 8.1.2 和 7.3.0 均验证。主题、示例和博客安装检查未报告已知依赖漏洞。
6. 发布后 23 个线上 HTML 页面均返回 200 并包含新版配置；主题 CSS/JS、Gallery CSS/JS 与 favicon 均与本地产物逐字节一致。

## 线上加载测量

使用 Lighthouse 13.4.1，在同一台机器上对生产 URL 顺序测量；手机模式、模拟 150ms RTT、约 1.6Mbps 吞吐、4 倍 CPU 减速。修改前后都测线上站点，未以本机服务器代替线上复测。

| 页面 | 修改前性能分 | 修改后性能分 | 修改前 LCP | 修改后 LCP | 修改后传输量 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 首页 | 81 | 100 | 5.29s | 1.07s | 453 KiB |
| 近期随想 | 100 | 100 | 1.07s | 1.07s | 41 KiB |
| Gallery 随机小展 | 88 | 99–100（三次） | 3.92s | 1.45 / 1.67 / 1.96s | 550–1,238 KiB |

首页传输量从 866 KiB 降至 453 KiB；文章页从 454 KiB 降至 41 KiB。修改后的上述五次测量均为 CLS 0、TBT 0，无障碍／最佳实践／SEO 均为 100。Gallery 修改前无障碍为 96、SEO 为 91，对应操作文字对比度与隐藏原图链接已修正。

Gallery 每次照片不同，前后得分和总流量不能视为同一组图片的严格 A/B。三次复测包含大约 0.54–1.21 MiB 的传输量；个别手机竖图会选到较大的 1600px 预览，后续可以增加中间尺寸。当前仅请求预览，打开大图才请求对应高清文件，未一次加载全部原图。

这些是实验室测量及浏览器仿真，不是真实访客的统计数据，也未覆盖实体 iPhone／Android、软键盘和各地区网络。因此结论是本轮范围内没有发现显著问题，不是保证所有设备和网络都相同。

## 复验入口

```bash
npm ci
npm run check
npm run audit:browser
npm run visual:capture && npm run visual:compare
```

浏览器完整结果保存在被 Git 忽略的 `tooling/audit/browser.json`，线上页面检查在 `tooling/audit/live-pages.json`，Lighthouse 原始报告为该目录下的 `lighthouse-*.json`；视觉结果在 `tooling/visual/report.md`。测试用 HTTP 服务仅在响应中移除 HTTPS 自动升级的 meta 标签，避免 WebKit 将本地 HTTP 请求升级；生产 HTML 保留该设置。

主题的独立验证和示例说明见 [主题 README](https://github.com/CHEology/hexo-theme-bluenote#readme)，Gallery 清单规范见 [模块说明](https://github.com/CHEology/hexo-theme-bluenote/blob/v1.1.0/modules/gallery/README.md)。
